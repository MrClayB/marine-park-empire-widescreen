# Marine Park Empire – Widescreen & UI scaling mod

Marine Park Empire (2005, 32-bit Direct3D 9) only supports 4:3 and shows black bars on a modern monitor.
This mod makes the game run at your desktop resolution, shows **more of the zoo at the sides instead of black bars**
(nothing is stretched), and rescales the menus and HUD to the new screen size.

It is a tiny `d3d9.dll` proxy that sits in the game folder. `mpe.exe` is **not** modified on disk and no game files are included here.

## What it does

- **Full-screen widescreen 3D view** at your desktop resolution: the world is rendered with the correct aspect ratio and you simply see more map left/right.
- **Main menu and menu pages** (Tutorial, Scenario, Free Game, Options, Load/Save…) are scaled up uniformly and centred. The Tutorial / Scenario / Free Game pages get black bars at the sides; the loading screens are drawn at their original 4:3 shape on black instead of being smeared.
- **In-game HUD** (button cluster, status bar, Animal / Staff / Visitor / build panels, tooltips) is enlarged and kept in the bottom-left corner, with the mouse hit-testing re-mapped so clicks, hover and drag/drop previews land on the right place.
- **Camera / photo overlay** fills the whole screen with its corner brackets and counters at the screen corners.
- **Mouse** works over the full screen, edge-scrolling and clicks on the 3D world / animal placement preview work as in the original.
- **Crash fixes** for the video-capture button (see Known issues).

## Compatible screens

The resolution is read from the primary monitor every time the game starts, so there is nothing to configure:

| Screen | Status |
|---|---|
| 2560×1440 (16:9) | tested, main target |
| Other 16:9 (1920×1080, 3840×2160), 16:10, ultrawide (3440×1440 …) | designed to work (all sizes are computed from the resolution); not tested yet |
| 4:3 / 1024×768 and smaller | no change (the game already fits) |
| Several monitors | uses the primary monitor's size |

Menus are scaled by `min(width/1024, height/768)`, the HUD by `1 + 0.6·(that − 1)`, so on very wide screens the menus stay centred with bars at the sides.

## Install

1. Copy `d3d9.dll` from `release/` into the game folder (next to `mpe.exe`). Keep a copy of the game's `VIDEO.DAT` (the mod rewrites it at start-up to your resolution).
2. Start the game.

**Uninstall:** delete `d3d9.dll` and restore your original `VIDEO.DAT`.

## Build

```
zig cc -target x86-windows-gnu -shared -O2 -std=gnu11 wide.c d3d9.def -o d3d9.dll
```

(`sites.h` holds the addresses of the game's cursor/mouse code that the mod redirects; it is generated by disassembly of the 2006 `mpe.exe` and only matches that exact build.)

## Known issues / limits

- Only matches the Steam build of `mpe.exe` (module base `0x400000`, addresses hard-coded).
- **Video recording does not work**: starting a WMV capture crashes inside the game's Windows Media code on current Windows even without this mod. The mod makes the recording button do nothing instead of crashing. The photo button hits the same capture code (its pixel-format bug is patched) but I have not tested it.
- UI click sounds are untouched by the mod; if you hear none, check Options → Audio.
- While a build/animal panel is open, hover highlight on the bottom-left buttons is disabled (clicks still work).
- Only tested on 2560×1440.
